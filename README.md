# Blinky-Board

A blinky board that i made with free-form wiring (aka no pcb, only wire ), but it still has a pcb file to be my reference point.
Small note: pcb has 10 leds but real life build only has 5 as hand wiring 10 leds that close would have been hell.

BOM: 555 timer, cd4017, 1k and 470 ohm resistor, 0.01 uF capacitor, 1 uF electrolytic capacitor, 10 leds, 50k varible resistor, 2 male socket pieces.
